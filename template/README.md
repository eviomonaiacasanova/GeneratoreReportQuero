# Template Suite

Base HTML/CSS/JS per creare pagine con stile coerente.

## Come usare
1. Copia `base.html` e rinominalo in `index.html`.
2. Modifica il contenuto delle sezioni secondo il progetto.
3. Usa `css/theme.css` per colori/font e `css/components.css` per i componenti.
4. Se servono menu o dialog, usa `js/app-base.js`.

## Struttura
```
reportTestVRLABattery/
├── base.html
├── css/
│   ├── theme.css
│   └── components.css
├── js/
│   └── app-base.js
├── assets/
└── lib/
```
